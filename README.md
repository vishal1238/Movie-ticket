# 🎬 CinemaBook - Cinema Hall Ticket Booking System (MERN MVP)

The full source code is located in the [`cinema-book`](./cinema-book/) folder:
- **Client**: [`cinema-book/client`](./cinema-book/client/) (React + Vite + Tailwind CSS)
- **Server**: [`cinema-book/server`](./cinema-book/server/) (Node.js + Express + MongoDB)
- **Comprehensive Documentation**: [`cinema-book/README.md`](./cinema-book/README.md)

### Quick Run:
```bash
# 1. Start MongoDB (if not already running)
# 2. Seed initial data
cd cinema-book/server
npm run seed

# 3. Start Server (serves both API & Frontend on port 5000)
npm start
```
Open **http://localhost:5000** in your browser!
